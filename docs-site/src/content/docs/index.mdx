## Up and running

One container, one data volume. Everything else is set on the Settings page.

```bash
docker run -d --name dealsieve -p 8080:8080 \
  -v dealsieve-data:/data \
  ghcr.io/morrismorrison/dealsieve:latest
```

See [Install and run](/dealsieve/guide/install/) for the details.
